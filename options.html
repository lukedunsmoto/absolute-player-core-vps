Settings

Player

How the player appears on pages it takes over.

Stacking

Force player above other page content

Some sites leave their own controls, overlays or click-catchers on top of the replaced video, which can hide the player or swallow clicks. This gives the player frame the highest possible z-index so it sits above them. Leave off unless a site actually covers the player — it can also place the player over menus and banners that are meant to be on top.

Applies immediately to players already on a page.

Transcoding

How videos are converted for playback.

Quality

Transcode quality

Encoder effort for streams that have to be re-encoded. Higher settings look better and compress harder, but convert more slowly — on large or high-resolution video, playback can end up waiting for the converter. Streams that are copied unchanged (most MKV video) are unaffected; for those, this only sets the audio bitrate.

NormalFastest High~2× slower Highest~3–4× slower

Remote files

Changes apply from the next playback. Local files are unaffected.

Network

How remote files are requested.

Redirects

Cache resolved (redirected) sources

When a URL redirects to the real file, remember where it landed and request each chunk from there — so a redirecting service is contacted once per playback instead of once per chunk. Much faster on sources behind a resolver. If the destination expires, it is re-resolved automatically. Turn off if a source rejects reused links.

Transfer

Network speed

Sets how much of a remote file is requested at a time. Faster connections benefit from larger chunks: fewer round-trips means less latency when seeking and higher throughput. On slower connections a large chunk stalls playback while it downloads.
